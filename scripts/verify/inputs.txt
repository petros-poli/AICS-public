# Inputs of scripts/verify.sh beyond what it discovers by itself.
#
# Discovered automatically: every Python project (packages/*, tools/* with a
# pyproject.toml, card/), its own directory as an input, and its dependencies
# from the path entries of [tool.uv.sources]. Listed here: what the code cannot
# discover, namely the files outside a project that its tests read, the
# dependencies of the non-Python checks, the release libraries and the
# packages whose change means every check.
#
# Format, one per line:  <node> <kind> <value>
#   everything  path <prefix>   a change under <prefix> selects every check
#   release     lib  <name>     packages/<name> gets a reproducible:<name> check
#   <node>      path <prefix>   a change under <prefix> selects <node>
#   <node>      dep  <node>     <node> is also selected when the other one is
# A <node> is a project directory (packages/aics-server, card, clients/aics-js)
# or one of the virtual nodes release-isolation, host-ops, vantage and verify-script. A prefix
# ending in "/" is a directory; anything else is one file. Lines naming a node
# that does not exist in the checkout are ignored.

# decides how every check runs, so a change to it selects every check too.
