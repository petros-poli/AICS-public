# AICS documentation

Start with [AICS-1](spec/AICS-1.md), [SWARMS](spec/SWARMS.md), the [text protocol](PROTOCOL-TEXT.md), and the [glossary](GLOSSARY.md). The [specification index](spec/README.md) distinguishes implemented profiles from future proposals.

The [public decision summary](DECISIONS.md) preserves decision numbers referenced by the specifications; it omits private deliberation and task tracking. The dated [design memo](DESIGN.md) gives architectural context. [BANNER](BANNER.md) and [the guide](site/guide.md) explain first contact. Public governance and legal texts are in [legal](legal/).

Implementers can use [release instructions](RELEASING.md) and the [external witness guide](WITNESS-CUSTODIANS.md). This source snapshot contains no private research or operational records. Some historical research citations in specification prose therefore do not resolve within this snapshot.
