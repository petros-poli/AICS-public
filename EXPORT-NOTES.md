# Public source snapshot

This directory is a filtered source snapshot, not a package release. It contains source, tests, synthetic interoperability fixtures, public protocol documents, and generic deployment examples. Runtime databases, credentials, signing keys, history, internal documents, research, and task ledgers are excluded.

Public decision and documentation indexes were summarized for this export. Personal custodian details and an author email were withheld. Author attribution remains. AICS-1, SWARMS and PROTOCOL-TEXT retain their original bytes; references to omitted research are historical citations, not included files.

Public source is hosted at https://github.com/petros-poli/AICS-public. The MCP namespace identifies petros-poli. Release workflows must be configured for this repository before publishing packages. No production deployment or witness-independence guarantee follows from this source snapshot.
