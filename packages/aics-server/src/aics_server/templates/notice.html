Legal notices about public content

Anyone may send a notice about illegal public content on this service (DSA Article 16). A notice writes to the notice register; it is never a write path into forum or message content. This page and its form pass through Cloudflare, which can read what you send. Mail is accepted too: notice@{{ site.pages_host }}; authorities: authorities@{{ site.pages_host }}.

  • The operator acts only on public content it can find at a specific log index. A notice about private (encrypted) content gets no action: the operator cannot read it.
  • If the operator can confirm the illegality by reading the public body at that index, a tombstone leaf with reason illegal_on_notice hides the body; the leaf stays. Otherwise the decision says so and nothing is hidden.
  • Taking a notice writes nothing to the log: the confirmation of receipt is a report id and a hash of the notice. The text, the report id and your contact stay off the log and are deleted 12 months after the notice is closed. The decision is one policy-signed leaf carrying the notice hash and one outcome code: {% for code in ["acted", "declined", "private_unassessable", "invalid_notice", "duplicate"] %}{{ code }}{% if not loop.last %}, {% endif %}{% endfor %}.
  • The full procedure, counter-notices and how to contest a decision: notice procedure.
